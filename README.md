# 자양교회 어린이 합창단 사이트

https://jayangchoir.github.io — 첫 화면은 누구나 보는 **공개 소개 페이지**이고, 오른쪽 위 **로그인** 하나로 모든 역할이 들어옵니다.
역할은 고르지 않습니다. 넣은 이름과 코드로 정해집니다. PC를 켜 두지 않아도 늘 동작합니다 (GitHub Pages + GitHub 저장소).

## 누가 무엇을 보나요

| 역할 | 들어가는 방법 | 볼 수 있는 것 |
|---|---|---|
| **공개** | 누구나 | 소개 · 입단 안내 (관리자가 고른 공연 영상) |
| **학부모** | **가족마다 하나**인 접속 코드 (이름 = 보통 아이 이름) | 노션에 있던 모든 내용: 공지 · 일정(달력·내 달력에 추가) · 연주곡(악보 PDF·연습 음원·참고 영상) · 영상 · 사진 · 명단(이름과 학년) · 회비 계좌번호 |
| **스탭** | **사람마다 하나**인 개인 코드 | 학부모 화면 + 연락처 명단(부모님 이름·전화·비고) · 예금주 · 문의 담당 · **회의자료**(첨부 파일) · **간식 당번**. 회의자료와 간식은 고칠 수 있어요 |
| **관리자** | 관리자 코드 (같은 로그인 화면. 어느 기기든 로그인하면 비공개 데이터까지 열림) | 모든 것 + 가족·스탭 코드 발급·회수 · 역할 바꾸기 · 모든 내용 편집 |

- **부모님 이름·연락처·비고, 예금주, 문의 담당 전화는 스탭·관리자만** 봅니다. 학부모용 내용은 허용한 칸만 옮기고(`js/bundle.js`), 올리기 전에 한 번 더 훑어서 연락처가 보이면 반영하지 않습니다. 그래서 가족 코드가 새어 나가도 연락처는 드러나지 않습니다.
- **가족이 탈퇴하면** 관리자 → 권한·코드 → 관리 → 탈퇴 처리: 그 가족의 자리를 지우고 학부모 열쇠를 바꿔 커밋 하나로 다시 올립니다. 그 뒤에 올린 것은 그 가족이 볼 수 없습니다. 이미 휴대폰에 받아 둔 것은 지울 수 없습니다. 남은 가족은 코드를 다시 넣지 않아도 됩니다.
- **스탭이 그만두면** 스탭 열쇠와 학부모 열쇠를 모두 바꿉니다(항목 키만 다시 감싸고 내용·파일은 그대로). 스탭 꾸러미에는 쓰기용 GitHub 토큰이 들어 있으므로 **설정 → GitHub 토큰 바꾸기**도 해 주세요 (화면이 빨간 알림으로 알려 줍니다).
- 이 권한 구조는 유년부·합창단·OZ 사이트가 함께 쓰는 공유 모듈(`js/core/access.js`, 명세 `js/core/ACCESS-SPEC.md`)입니다. 합창단 설정은 `js/access-config.js`.
- 지우기는 모두 **휴지통**이고, 탈퇴한 가족 기록도 "탈퇴·회수"에 남아 다시 가입시킬 수 있습니다.

## 처음 한 번 (임원)

1. **GitHub 저장소 두 개** (계정 `jayangchoir`)
   - `jayangchoir.github.io` — 공개. 이 폴더의 파일을 올리고 Settings → Pages → Branch `main` / `(root)`.
   - `jayangchoir-data` — **비공개(Private)**, 비어 있어도 됨.
2. **토큰 만들기** — GitHub → 오른쪽 위 사진 → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token
   - Token name: `jayangchoir-site-2026` / Expiration: 가장 길게(1년) — **만료일을 달력에 적어 두세요**
   - Resource owner: `jayangchoir` / Repository access: **All repositories** (사진 저장소 `choir-photos-N` 을 사이트가 저절로 만들기 때문)
   - Repository permissions: **Contents: Read and write**, **Administration: Read and write** (저장소 만들기), Metadata: Read-only(저절로)
   - 만들기가 막히면 GitHub에서 `choir-photos-1` 을 **공개(Public)** 로 직접 만들어도 됩니다 (README 하나 넣어서).
3. 사이트 → 로그인 → 아래 "처음 설정·관리자 코드 분실" (또는 `#/admin`) → **처음 설정**: 토큰, 관리자 데이터 비밀번호(비상용), 내 이름, 관리자 로그인 이름 →
   **관리자 코드 · 명단 복구 코드 · 데이터 복구 코드** 세 가지를 종이에 적기 (다시 볼 수 없음). 그다음부터 관리자도 로그인 화면에서 관리자 코드로 들어옵니다.
4. 관리자 → **가져오기**
   - **준비된 자료 JSON** (`jayangchoir-seed.json`, 노션 공개 페이지에서 미리 옮긴 것: 첫 화면 글·일정 표·회비·활동 안내·연주곡 링크·공연/연습 영상·명단). 불러온 뒤 그 파일은 지우세요(연락처가 들어 있음).
   - **노션 zip**: 노션 페이지 → ··· → 내보내기 → *Markdown & CSV*, *하위 페이지 포함* → 받은 zip. 전체일정 데이터베이스, 사진첩 사진, 악보 PDF(14개)를 가져옵니다. 노션 페이지는 그대로 둡니다.
5. 관리자 → **권한·코드** → **명단으로 가족 만들기** (연락처가 같은 형제·자매는 한 가족) → 다 만들면 안내문이 한꺼번에 나옵니다.
   가족마다 복사해 그 가족에게만 보내거나 카드로 인쇄하세요. **코드는 이때 한 번만 보입니다**(어디에도 저장하지 않음). 놓치면 "새 코드".
   스탭은 **스탭 추가**로 사람마다 개인 코드를 만듭니다. 관리자 → **공개 페이지**에서 소개 글과 공개할 공연 영상을 고릅니다.
6. 가족은 초대 메시지의 주소를 누르고 코드를 넣으면 됩니다. 한 번 넣으면 그 휴대폰에서는 다시 묻지 않습니다.
   - 접속 코드는 60비트 무작위(예: `K7QX-M2PA-9TRD`)이고 칸은 PBKDF2-SHA256 60만 회로 잠가서, 공개된 keyring 으로 코드를 맞히는 것은 사실상 불가능합니다.
   - 서버가 없어서 "누가 언제 들어왔는지"는 기록되지 않습니다. 잃어버리면 관리자가 **새 코드**를 만듭니다.
   - 가족이 원하면 로그인 뒤 홈 맨 아래 "내 코드를 비밀문장으로"에서 나만 아는 문장(10자 이상)으로 바꿀 수 있습니다. 학부모는 직접 올릴 수 없어서
     나온 요청 글자(ACX1.…, 비밀문장은 안 들어 있음)를 관리자에게 보내고, 관리자가 권한·코드 → "비밀문장 바꾸기 요청 적용"에 붙여 넣습니다.

## Google 설정 (사진 원본 보관, 한 번만)

사진을 올릴 때 **원본**을 합창단 Google 계정에 따로 보관합니다. 사이트에 올라가는 것은 줄이고 위치 정보(EXIF)를 지운 사본입니다.

1. `jayangchoir@gmail.com` 으로 https://console.cloud.google.com 에 로그인 → 새 프로젝트 `jayangchoir-site`.
2. API 및 서비스 → 라이브러리 → **Photos Library API** 사용. (예비용으로 **Google Drive API** 도 사용)
3. OAuth 동의 화면 → User Type **외부** → 앱 이름 "자양교회 어린이 합창단", 지원 이메일 jayangchoir@gmail.com →
   범위는 비워 둬도 됨 → **테스트 사용자**에 `jayangchoir@gmail.com` 과 사진을 올릴 임원들의 Gmail 을 넣기 → **게시 상태는 "테스트"로 둡니다.**
4. 사용자 인증 정보 → 사용자 인증 정보 만들기 → **OAuth 클라이언트 ID** → 애플리케이션 유형 **웹 애플리케이션** →
   승인된 자바스크립트 원본: `https://jayangchoir.github.io` 과 `http://localhost:8080` (PC에서 시험할 때 쓰는 주소·포트) → 만들기.
5. 나온 **클라이언트 ID**(`…apps.googleusercontent.com`)를 사이트 관리자 → 설정 → "사진 원본 보관 (Google)" 에 붙여 넣고 저장.
6. 사진을 올릴 때 Google 로그인 창이 뜨면 **꼭 jayangchoir@gmail.com 으로** 로그인하고 권한에 체크합니다.
   - 로그인 정보(토큰)는 이 탭에만 1시간 남고, 관리자 화면을 잠그면 취소됩니다. 원본 올리기가 실패해도 사이트 올리기는 따로 끝나고, 상황판의 **원본 다시**로 다시 올립니다. 새로고침해도 대기열은 남습니다.
   - Google 포토가 막히면(브라우저 보안 또는 권한) 설정에서 보관할 곳을 **Google Drive** 로 바꾸세요 ("합창단 사진 원본/<앨범>" 폴더).
   - 테스트 모드 앱의 Google 로그인은 7일마다 다시 동의를 물을 수 있습니다.

## 자주 하는 일

- **휴대폰에서 빠르게**: 관리자 화면 오른쪽 아래 **+** → 일정 추가 / 공지 쓰기 / 사진 올리기 / 악보 PDF 올리기.
- **사진 올리기**: 사진 → 사진첩(행사+날짜) → 사진·PDF 올리기 → 여러 장 고르기. 긴 변 1600px·400KB 이하로 줄이고 작은 그림(400px)을 따로 만듭니다. 진행 막대가 보이고, 끊기면 이어서 올립니다.
- **PDF**: 20MB 넘으면 한 번 더 묻고, 95MB 넘으면 올리지 않습니다. 학부모는 "보기"(PC는 화면 안, 휴대폰은 새 탭)·"내려받기"(원래 이름)로 엽니다.
- **학부모 화면에 반영**: 고친 뒤 20초 지나면 저절로, 또는 위의 "지금 반영". 1~2분 뒤 학부모 화면에 보입니다.
- **코드 잃어버림·남에게 보임**: 권한·코드 → 관리 → 새 코드 (예전 코드는 바로 못 씀) → 새 안내문.
- **역할 바꾸기**: 권한·코드 → 관리 → 스탭으로 / 스탭에서 빼기 (스탭에서 빼면 스탭 열쇠를 바꿈).
- **관리자 코드를 잃었을 때**: 로그인 화면 아래 "처음 설정·관리자 코드 분실" → 관리자 데이터 비밀번호 + 명단 복구 코드 → 새 관리자 코드.
  (공개 저장소의 git 기록에는 예전 암호문이 남습니다. 탈퇴 전의 열쇠를 가진 사람은 그때까지의 내용은 볼 수 있지만, 그 뒤의 내용은 못 봅니다.)
- **새 관리자·스탭 휴대폰**: 따로 연결할 것 없이 로그인 화면에서 자기 코드로 들어오면 됩니다 (관리자 코드는 데이터 저장소까지 엽니다).
- **토큰 바꾸기, 임원이 바뀔 때**: 설정 → GitHub 토큰 바꾸기 (스탭들 꾸러미에도 새 토큰이 들어감), 새 임원은 권한·코드에서 관리자 또는 스탭으로 추가. 데이터 저장소 쪽 자세한 내용은 [js/core/HANDOVER.md](js/core/HANDOVER.md)
